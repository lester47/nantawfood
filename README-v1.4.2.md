# v1.4.2 教學現場專用版

## 版本定位

- 以 `v1.4` 為基礎簡化操作流程
- 保留 **小組代碼、手機體感、即時排行榜**
- 移除主畫面上較容易讓現場混亂的額外操作按鈕

## 這版做了什麼簡化

- 主畫面只保留：
  - MQTT 連線狀態
  - 小組代碼顯示
  - 手機控制器入口
  - 排行榜入口
- 統一把畫面文案改成「小組」
- 排行榜改成自動顯示全部小組，不再提供畫面內篩選與手動清空
- 保留手機體感與「手動送出一步」備援

## 使用方式

1. 開啟主畫面：`index.html`
2. 讓學生開啟手機控制器：`player.html?room=小組代碼`
3. 查看排行榜：`leaderboard.html`

## 適用情境

- 國小 / 國中教學現場
- 老師希望操作越少越好
- 學生只要專注在跑步、選隊伍、看排行榜
