一般使用者：啟用本機 AI 串接

AI 串接是選用功能。網站不提供 API Key；要串接 AI，請使用你自己的 OpenAI API 金鑰。不串接也可以正常使用，系統會採用事先整理好的備用教材與解說。

適用 Windows 10／11 電腦。BAT 會下載本平台網站、建立獨立 Python 環境，啟動 AI 服務與本機網頁。第一次需連網下載約 110 MB 網站檔案及 Python 套件，請耐心等候；不需安裝 Git 或自行輸入指令。

下載 Windows 啟動 BAT

第一次使用

  1. 先安裝 Python 3.11 或更新版。安裝時勾選 Add Python to PATH。已安裝者可直接下一步。
  2. 下載上方 start-local-ai.bat，儲存到電腦後雙擊執行。若檔名變成 .bat.txt，請重新下載並保留 .bat 副檔名。若瀏覽器或 Windows 阻擋下載，請先確認來源是本平台；由學校管理的電腦請洽資訊人員處理。
  3. 等候下載及安裝完成。檔案存放於 %LOCALAPPDATA%\NantouFoodAI，之後啟動會沿用已安裝的檔案。
  4. 程式會自動開啟 本機網站 http://127.0.0.1:8765/index.html。請在這個頁面的「AI 金鑰設定」輸入自己的 API 金鑰，保留原有模型或填入自己有權限的模型名稱。
  5. 依序按「儲存設定」與「測試 AI 連線」。顯示連線成功後，按「完成設定，開始遊戲」，即可使用回合後的 AI 教學。

以後怎麼使用、如何關閉？

每次雙擊同一個 BAT 即可。使用期間保留啟動視窗；結束時回到視窗按 Enter，會停止這次啟動的兩個服務。重新啟動後需再次輸入金鑰。若直接關閉視窗後出現連接埠已使用，可先重新啟動電腦，再執行 BAT。

金鑰只保留在本機 AI 服務記憶體，不寫入 BAT 或設定檔。呼叫 AI 會使用你的 API 額度；不設定金鑰仍可使用事先整理好的備用教材與解說。手機掃描首頁 QR code 開啟的是公開網站，不會啟動電腦上的 BAT 或本機 AI。

常見問題

  • 找不到 Python：重新安裝 Python 並勾選 PATH，完成後重新執行 BAT。
  • 首次下載或套件安裝失敗：確認能連上 GitHub 及 Python 套件網站，再次執行 BAT；不要在下載進行中關閉視窗。
  • 8000 或 8765 已被占用：回到先前的啟動視窗按 Enter 結束服務，或關閉使用該連接埠的程式。
  • AI 服務未啟動：確認啟動視窗顯示 Ready，並使用 BAT 自動開啟的本機頁面。公開網站仍可使用一般教材功能。
  • 測試 AI 失敗：依畫面訊息確認金鑰、模型使用權限、API 額度與網路。不要把金鑰貼到錯誤截圖中。
  • 需要重新下載最新版：停止本機服務後，刪除 %LOCALAPPDATA%\NantouFoodAI\setup-r24.ready，再執行 BAT，會重新下載與安裝。
