# v1.5.0 AI 關卡整合版：實作計畫

## 版本定位
- 目標版本：`v1.5.0`
- 版本性質：MINOR（在既有 v1.4.2 教學現場版上新增 AI 互動關卡）
- 兼容原則：保留既有 MQTT 跑步、攻佔、排行榜與老師操作流程

## 核心整合目標
1. 在舊版 `index.html` 遊戲流程中插入 AI 問答關卡
2. 使用既有 `api-mvp` 的 `POST /api/v1/ai/ask` 能力（LLM + fallback）
3. 僅先支援 4 食材 mapping（埔里/鹿谷/草屯/魚池），其餘鄉鎮顯示暫未開放 AI
4. AI 失敗不阻塞回合：仍可安全進入下一回合

## 流程變更（舊流程 → 新流程）
- 舊：攻佔成功 → 食材語音介紹 → 回合重置
- 新：攻佔成功 → 食材語音介紹 → AI 問答彈窗（1 題）→ 回合重置

## 技術設計
### 前端（legacy `index.html`）
- 新增 AI 問答 overlay/modal（輸入、送出、回答、跳過）
- 新增 `townToProductSlug` 對照（4 筆）
- 新增 `askAi(productSlug, question)` API 呼叫
- 新增流程控制旗標，避免與原本 `introPlaying` 衝突

### API 呼叫策略
- 預設：`http://127.0.0.1:8000/api/v1/ai/ask`（本機開發）
- 預留：可改為同網域 BFF `/api/ai/ask`（若後續以 web-mvp 反向代理）

### 錯誤容錯
- request timeout / non-2xx / JSON parse fail → 顯示友善訊息並允許繼續
- 未映射鄉鎮 → 顯示「該鄉鎮 AI 問答即將上線」，不擋關
